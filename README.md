# shinonomekazan/muse

株式会社東雲火山が、業務の中で Muse を活用する中で生まれたもののうち、**公開に値すると考えられるノウハウや成果物を共有する場所**です。

社内の情報や顧客の情報を含むものは置きません。ここにあるのは、他の組織や個人が自分の環境でも再利用できる形に切り出したものだけです。

## 収録内容

### apps/

Muse に作らせたアプリのうち、他の人の Muse でも再現できるようにしたパッケージを置きます。
各パッケージはアプリ本体のコードではなく、「自分の Muse に URL を渡すと、同じアプリを作ってくれる」ための再現指示と仕様書です。アプリのデータ自体は共有されません。

- [apps/todo-space](./apps/todo-space/) — 今日／明日以降／過去を左右の空間として扱う Todo アプリの再現パッケージ

## 使い方

各パッケージの README に、そのパッケージごとの使い方が書いてあります。
基本的には、パッケージの URL を自分の Muse に送り、再現指示（PROMPT.md）を読んで作るよう頼むだけです。
