# Todoリスト（空間Todo）— Muse再現パッケージ

「今日 / 明日以降 / 過去」を左右の空間として扱う、少し変わったTodoアプリです。
このフォルダは、アプリ本体のコードではなく、**他の人の Muse が同じアプリを再現するためのパッケージ**です。

## どんなアプリか

- タスクは「空間」に置かれます。デフォルトは一番左の **今日**
- 右の空間は「先送り」です。1つ右＝明日までやらない、2つ右＝二日後までやらない、…と**右に上限はありません**
- 左の空間は「過去」です。完了したタスクだけが、日が変わるごとに左へ移っていきます
- 画面に一度に出るのは **1つの空間だけ** です。今日の画面には、明日のタスクも昨日の完了も、件数や見出しを含めて一切出ません。「明日やるものが目に入ると気になる」「昨日完了したものをいちいち見たくない」という人間の認識に合わせた設計です
- データは使う人自身の Muse 環境に保存されます。他の人のデータは共有されません

詳しい仕様は [SPEC.md](./SPEC.md) を参照してください。

## 自分の Muse で同じものを作る方法

1. このフォルダの URL を、自分の Muse とのチャットに送る
2. あわせて、次のように頼む（コピー＆ペーストでそのまま使えます）

> このフォルダの PROMPT.md を読んで、その指示どおりにアプリを作ってください。
> https://github.com/shinonomekazan/muse/blob/main/apps/todo-space/PROMPT.md

3. Muse が保存機能付きのアプリとして作成します。作成後は、その人自身のデータで使い始められます

## 注意

- このパッケージを共有しても、**作成者の Todo データは共有されません**。共有されるのは「作り方」だけです
- 再現されるアプリは、各人の Muse 環境の中で動く個人用アプリです。複数人で同じリストを共同編集する用途には向きません
- 日付の変わり目は、使う人のローカルタイムゾーンの日付で判定します

## ファイル構成

- `README.md` — このファイル。人間向けの説明
- `PROMPT.md` — Muse にそのまま渡すための再現指示（自己完結）
- `SPEC.md` — 機能仕様・データモデル・受け入れ基準
