# 再現指示（Muse 向け）

このファイルを読んだ Muse は、以下をそのまま実行してください。
ユーザーに仕様の確認を繰り返さず、この指示を完成仕様としてアプリを1つ作成してください。

## 作るもの

- 種類: **保存機能付きの対話型アプリ**（Muse の fullstack / interactive app。静的ページでは作らないこと。入力したデータがアプリ専用の保存領域に残り、閉じて開き直しても消えないことが必須）
- 名前: 「Todoリスト」
- 目的: 今日やることに集中するための、空間概念を持つ Todo リスト

## 完成仕様

### 1. 追加（入力）

- 入力は最初は **タイトルのみ**
- テキストエリアに **1行に1件** 書いて一括追加できる。追加ボタンには件数を表示する（例:「3件を追加」）
- 新規タスクのデフォルト位置は「今日」（先送り日数 0）
- 追加したら表示は今日の空間に戻り、追加分が見える

### 2. 各タスクの操作

- タスクをタップすると詳細が開き、そこで以下ができる
  - タイトルの修正
  - 詳細メモ（説明文）の記入・編集
  - 完了にする（完了ボタン）
  - 未完了に戻す
  - 先送り日数の変更（「1日戻す」「1日先送り」ボタンと、日数の直接指定）
  - 並び替え（上へ／下へ）
  - 削除（2段階確認など、誤操作を防ぐ形）
- **完了の方法は次の2つだけ**。行の左端にチェックボックスは置かない
  - タスク行の **ダブルタップ**
  - 詳細の中の **「完了にする」ボタン**
- シングルタップは詳細を開く動作と競合させないこと

### 3. 空間モデル（右＝未来への先送り）

- 各タスクは「先送り日数」という非負整数を持つ。0＝今日、1＝明日までやらない、2＝二日後までやらない、以下同様
- **右方向に上限はない**（30日なども保存・表示できること）。空間モデルの概念としての「無限」であり、実装上の技術的な上限が人間の一生より十分に大きい範囲（例: 36500日＝100年）にある場合は、上限なしとみなしてよい
- 各タスクは **左右フリック（スワイプ）で1日ずつ** 移動できる。スワイプ中は移動先が分かる表示を出す（例:「明日へ →」）
- **日付が変わると、先送り日数は自動で1減る**。ただし 0 未満にはならない（今日に着いたタスクは今日に留まる）
- 日付判定はユーザーのローカルタイムゾーンの暦日で行う

### 4. 空間モデル（左＝過去の完了履歴）

- 完了したタスクには **完了日** を記録する
- 今日完了したタスクは、今日の空間の下部「完了済み」に表示する
- **日付が変わると、完了済みタスクだけが左へ1日分移る**。「昨日完了」「2日前に完了」のように、完了してからの経過日数でグルーピングして表示する
- **未完了タスクは過去へ移らない**
- 過去の完了タスクを未完了に戻すと、今日の空間（先送り日数 0）に戻る
- 完了済みタスクをまとめて削除する操作を用意する

### 5. 表示（1空間だけ見せる）

- 一覧に一度に表示するのは **選択中の1つの空間だけ**
- 今日の画面には、他の空間のタスクを **件数・見出し・バッジを含めて一切表示しない**。ここでいう「表示しない」は視覚上の表示のことであり、スライドアニメーションのために他の空間の列が画面外に描画されていること自体は妨げない
- 空間移動:
  - 画面上部の入力エリアまわりを **左右スワイプ** すると空間を1つずつ移動できる。スワイプは入力エリア周辺の余白・ラベル・ナビゲーション部分から開始できればよい。テキストエリアや入力欄そのものの上からは、文字入力・文字選択を妨げないため開始できなくてよい
  - 現在の空間名を中央に表示し、ボタンでも移動できるようにする
  - 今日以外の空間にいるときは「今日に戻る」を表示する
  - 移動範囲は、タスクが存在する空間まででよい
- 空間の切り替えアニメーション:
  - 列が横一列につながった帯（ストリップ）をスライドさせる、Trello のような動きにする
  - ドラッグ中は列全体が指に追随し、離すと **ページ単位でスナップ** する（途中の位置で止まる必要はない）
  - 端ではラバーバンドのような抵抗を付ける
  - ボタンでの移動も同じスライドアニメーションを使う
  - 空間ごとの高さの違いには滑らかに追随する

### 6. 説明文

- アプリ内の説明文（使い方など）は **デフォルトで閉じた状態** にし、初期画面を縦長にしない
- 「？」ボタンを置き、クリックしたときだけツールチップ／ポップオーバーで説明を表示する

### 7. データ

- 最初は空の状態で始める。サンプルデータや検証用データを本番データに入れない
- 保存先はアプリ専用の保存領域のみ。他のユーザーとデータは共有されない

## 受け入れ基準（作成後に自分で確認すること）

- [ ] 3件を1行ずつ書いて一括追加でき、ボタンに件数が出る
- [ ] 1件を先送り3日に設定し、日付を1日進めた想定で先送り2日になる（0未満にならない）
- [ ] 30日の先送りが上限なく保存・表示できる
- [ ] ダブルタップと、詳細の完了ボタンの両方で完了できる。左端チェックは無い
- [ ] 今日完了したタスクが今日の「完了済み」に残り、翌日には「昨日完了」へ移る
- [ ] 未完了タスクは日付が変わっても過去へ移らない
- [ ] 今日の画面に、他の空間のタスク・件数・見出しが一切出ない
- [ ] 入力エリアのスワイプで空間移動でき、列が指に追随して滑ってページ単位で止まる
- [ ] 説明文がデフォルトで閉じている
- [ ] 閉じて開き直してもデータが残っている
